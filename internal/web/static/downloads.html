LOCAL COMPUTER CONTROL

Agent V Bridge

Install the small Agent V companion on the computer you want Agent V to control. Keep it running, then ask Agent V to open apps, play music, or perform browser actions.

Windows

Download both files into the same folder, then run the PowerShell setup from a terminal. It starts Agent V when you sign in.

Download AgentV.exeDownload setup script

Linux

Download the installer script and run it from Terminal. It installs Agent V as a per-user systemd service.

Download agent-v-linux-amd64Download install-agent-v.sh

After installation, enter the same Agent V token configured on this server. The companion polls securely over outbound HTTPS; it does not expose your computer directly to the internet.
